# TopFlight Homebrew tap

```bash
brew install richierob/topflight/topflight
```

Or:

```bash
brew tap richierob/topflight
brew install topflight
```

Then `topflight --help`. The commands are `init`, `snapshot`, `run` and `gas`.

[Bot kit and source](https://github.com/RichieRob/topflight-bot) · [Bot brief](https://raw.githubusercontent.com/RichieRob/topflight-bot/main/topflight-for-bots.md)

The formula installs the versioned kit from its Git tag and verifies the archive SHA256.
It uses your local wallet and sends native Sepolia transactions. The current venue is a
play-money beta. The kit's source, license, tests and deployment manifest are in the bot repo.
